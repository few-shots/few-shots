Yes!

Adaptation: the original instance bytes are zlib-compressed and base64-
encoded inside verify/verify.py. Loading reverses this encoding, checks
the source digest and parses the unchanged row-major integer matrix.

The non-commercial condition applies to the embedded matrix. Public
redistribution is permitted in the specific non-commercial benchmark
described above. The matrix is not relicensed under the repository's
Apache-2.0 code licence or CC0 data declaration. Verifier code retains
the repository code licence; that licence does not cover this matrix.
